# GNN / BERT / CNN / Contrastive Music Project

This repository contains four related music-learning workflows:

- BERT lyrics classification using GTZAN transcriptions
- GraphSAGE chord-transition classification using GTZAN audio
- CNN mel-spectrogram classification using GTZAN audio
- Cross-modal contrastive learning between MusicCaps audio graphs and captions

The project is organized around a shared raw dataset and several processed outputs generated by different scripts.

## 2. Which file creates which data file

### A. Raw audio and lyrics pipeline

| Script | Purpose | Output files created |
|---|---|---|
| `src/extract_lyrics.py` | Runs Whisper transcription for audio files and writes lyrics metadata | `data/processed/lyrics_transcriptions.csv` |
| `src/bert_encoder.py` | Reusable BERT encoder and tokenizer helper | imported by training and fusion scripts |
| `src/train_bert_task1.py` | Selects balanced rows, trains BERT, evaluates and saves Task 1 artifacts | `data/processed/lyrics_transcriptions_balanced.csv`, `data/processed/genre2id.json`, `data/processed/bert_genre_model.pt`, `data/processed/bert_genre_model_best.pt`, `data/processed/confusion_matrix.png`, `data/processed/f1_curves.png` |

Notes:
- `extract_lyrics.py` works from the raw audio folder: `data/raw/Data/genres_original/.../*.wav`
- `bert_encoder.py` reads the processed transcription CSV and produces the balanced dataset + trained model.

### B. Graph / GNN pipeline

| Script | Purpose | Output files created |
|---|---|---|
| `src/audio_features.py` | Core audio feature extraction and chord template logic | helper module used by graph scripts |
| `src/graph_builder.py` | Builds chord-transition graphs from raw audio | `data/processed/chord_graphs/*.json`, `data/processed/chord_graphs_excluded/` (if used), `data/processed/excluded_tracks.txt` |
| `src/dataset_loader.py` | Converts graph JSON files into PyTorch Geometric datasets | `data/processed/train_dataset.pt`, `data/processed/val_dataset.pt`, `data/processed/test_dataset.pt` |
| `src/train.py` | Trains the GraphSAGE model | `results/best_model.pt`, `results/plots/training_curve.png` |

Notes:
- `graph_builder.py` is the graph-building stage. It creates one JSON per track.
- `dataset_loader.py` is the dataset-prep stage. It must run after graph JSON files exist.
- `train.py` reads the `.pt` datasets and trains the GNN.

### C. CNN / mel spectrogram pipeline

| Script | Purpose | Output files created |
|---|---|---|
| `src/mel_spectrogram_extractor.py` | Computes log-mel spectrograms for each wav file and stores them as `.npy` | `data/processed/mel_spectrograms/*.npy`, `data/processed/mel_spectrograms/labels.csv` |
| `src/train_cnn.py` | Trains the CNN on spectrograms | `results/best_cnn_model.pt`, `results/plots/cnn_training_curve.png` |

Notes:
- The CNN pipeline uses the spectrograms under `data/processed/mel_spectrograms/`.
- It is independent from the GNN and BERT pipelines, but it uses the same GTZAN genre labels.

### D. GNN-BERT fusion pipeline

| Script | Purpose | Output files created |
|---|---|---|
| `src/fusion_dataset_loader.py` | Intersects valid chord graphs with lyrics containing at least five words and creates stratified fusion splits | `data/processed/fusion_train_dataset.pt`, `fusion_val_dataset.pt`, `fusion_test_dataset.pt` |
| `src/fusion_model.py` | Defines GNN-only, BERT-only, concatenation, and cross-attention fusion models | imported by training scripts |
| `src/train_fusion.py` | Trains and evaluates all four fusion variants with resumable checkpoints | `results/fusion_*_best.pt`, `results/checkpoints/*_checkpoint.pt`, `results/task3_ablation_results.csv`, `results/fusion_*_predictions.csv` |
| `src/plot_tsne.py` | Extracts cross-attention fused embeddings and creates a t-SNE plot | `results/plots/tsne_fusion_embeddings.png` |

`train_fusion.py` automatically creates missing fusion dataset files. It saves a full checkpoint after every epoch and resumes unfinished model variants.

### E. MusicCaps contrastive pipeline

| Script | Purpose | Output files created |
|---|---|---|
| `src/download_musiccaps.py` | Loads MusicCaps metadata, downloads the first 300 available YouTube clips, trims them to the requested windows, and logs failures | `data/raw/musiccaps_audio/*.wav`, `data/raw/musiccaps_metadata.csv`, `data/raw/musiccaps_failed.log` |
| `src/build_musiccaps_graphs.py` | Builds 10-second MusicCaps chord-transition graphs using smoothing window 5 and minimum duration 0.5 seconds | `data/processed/musiccaps_graphs/*.json` |
| `src/contrastive_dataset_loader.py` | Converts MusicCaps graph-caption pairs into PyG datasets | `data/processed/contrastive_train_dataset.pt`, `contrastive_val_dataset.pt`, `contrastive_test_dataset.pt` |
| `src/contrastive_model.py` | Defines the GraphSAGE-BERT shared embedding model with symmetric InfoNCE loss | imported by training and evaluation scripts |
| `src/train_contrastive.py` | Trains the cross-modal model with resumable checkpoints | `results/contrastive_best_model.pt`, `results/checkpoints/contrastive_checkpoint.pt`, `results/plots/contrastive_training_curve.png` |
| `src/evaluate_retrieval.py` | Measures caption-to-audio and audio-to-caption retrieval | `results/task4_retrieval_results.csv`, `results/task4_qualitative_examples.txt` |

Current contrastive training settings are batch size `8`, BERT learning rate `5e-6`, GNN/projection learning rate `5e-4`, temperature `0.15`, and gradient clipping at `1.0`.

### F. Debug and validation scripts

| Script | Purpose | Output files created |
|---|---|---|
| `src/debug_single_track.py` | Tests a single track for chord smoothing behavior | no permanent dataset output; prints diagnostics to console |
| `src/debug_sample_tracks.py` | Samples tracks to validate smoothing parameter choices | no permanent dataset output; prints diagnostics to console |
| `src/check_degenerate_graphs.py` | Checks for empty or degenerate graph structures | no permanent dataset output; prints diagnostics to console |
| `src/check_musiccaps_degenerate.py` | Checks MusicCaps graph quality and identifies degenerate graphs | diagnostics and exclusion information |
| `src/check_lyrics_coverage.py` | Reports usable lyrics coverage and fusion readiness | console diagnostics |

## 3. Recommended execution order

Run these in the following order from the project root.

### Stage 0: Prepare the project environment

From the root folder:

```bash
cd C:\studymatt\425\gnn-bert-music-context
```

Then run scripts using Python from the project root, for example:

```bash
python src/extract_lyrics.py
```

---

### A. BERT pipeline

Recommended order:

1. `python src/extract_lyrics.py`
   - Creates `data/processed/lyrics_transcriptions.csv`
2. `python src/train_bert_task1.py`
   - Creates balanced lyrics dataset and model outputs

Do not run `bert_encoder.py` as the training entry point. It is a reusable module imported by Task 1 and Task 3.

Files produced:
- `data/processed/lyrics_transcriptions.csv`
- `data/processed/lyrics_transcriptions_balanced.csv`
- `data/processed/genre2id.json`
- `data/processed/bert_genre_model.pt`
- `data/processed/bert_genre_model_best.pt`
- `data/processed/confusion_matrix.png`
- `data/processed/f1_curves.png`

---

### B. GNN pipeline

Recommended order:

1. `python src/graph_builder.py`
   - Creates `data/processed/chord_graphs/*.json`
2. `python src/dataset_loader.py`
   - Creates `data/processed/train_dataset.pt`, `val_dataset.pt`, `test_dataset.pt`
3. `python src/train.py`
   - Reads the `.pt` files and trains the GraphSAGE model

Files produced:
- `data/processed/chord_graphs/*.json`
- `data/processed/train_dataset.pt`
- `data/processed/val_dataset.pt`
- `data/processed/test_dataset.pt`
- `results/best_model.pt`
- `results/plots/training_curve.png`

Optional validation scripts before full batch:
- `python src/debug_single_track.py`
- `python src/debug_sample_tracks.py`
- `python src/check_degenerate_graphs.py`

---

### C. CNN pipeline

Recommended order:

1. `python src/mel_spectrogram_extractor.py`
   - Creates `data/processed/mel_spectrograms/*.npy`
   - Creates `data/processed/mel_spectrograms/labels.csv`
2. `python src/train_cnn.py`
   - Reads the mel spectrograms and trains the CNN

Files produced:
- `data/processed/mel_spectrograms/*.npy`
- `data/processed/mel_spectrograms/labels.csv`
- `results/best_cnn_model.pt`
- `results/plots/cnn_training_curve.png`

---

### D. GNN-BERT fusion pipeline

Run after the GTZAN graph and lyrics artifacts are available:

```bash
python src/fusion_dataset_loader.py
python src/train_fusion.py
python src/plot_tsne.py
```

`train_fusion.py` trains four independent variants. It can be interrupted and rerun; completed variants are skipped and incomplete variants resume from `results/checkpoints/`.

---

### E. MusicCaps contrastive pipeline

Install the runtime dependencies first:

```bash
pip install yt-dlp datasets
```

Make sure `ffmpeg` is installed and available on `PATH`. Then run:

```bash
python src/download_musiccaps.py
python src/build_musiccaps_graphs.py
python src/contrastive_dataset_loader.py
python src/train_contrastive.py
python src/evaluate_retrieval.py
```

The downloader is resumable and skips existing WAV files. YouTube availability changes over time, so a success rate below 100% is expected. The graph builder and contrastive dataset loader are also resumable or safe to rerun.

---

## 5. Notes

- Most scripts can be run from the project root. Paths are resolved from each script's location; running from `src` also works for the current scripts.
- `download_musiccaps.py`, `build_musiccaps_graphs.py`, `train_fusion.py`, and `train_contrastive.py` are resumable.
- `debug_*` scripts are for parameter tuning and troubleshooting, not the final training pipeline.
- The GTZAN classification tasks use: `blues`, `country`, `disco`, `hiphop`, `metal`, `pop`, `reggae`, `rock`.
- MusicCaps is caption-based and does not provide the same eight genre labels.

---

## 6. Quick summary

- BERT learns from lyrics: `lyrics_transcriptions.csv` -> `train_bert_task1.py` -> `bert_genre_model.pt`
- GNN learns from chord graphs: `chord_graphs/*.json` -> `train_dataset.pt` -> `best_model.pt`
- CNN learns from mel spectrograms: `mel_spectrograms/*.npy` -> `best_cnn_model.pt`
- Fusion compares graph-only, BERT-only, concatenation, and cross-attention models.
- Contrastive learning aligns MusicCaps graphs and captions: `musiccaps_audio/*.wav` -> `musiccaps_graphs/*.json` -> contrastive datasets -> retrieval metrics.
